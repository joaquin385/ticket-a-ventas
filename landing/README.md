# Landing — Ticket a Ventas

Sitio estático para **Cloudflare Pages**.

## Deploy

1. En [Cloudflare Pages](https://pages.cloudflare.com): Create project → Upload assets o conectar el repo.
2. **Root directory**: `landing`
3. Build command: _(vacío)_ — Build output: `/` (o `.`)
4. Variable opcional en el HTML: abrí con `?wa=54911XXXXXXXX` o editá el fallback en `index.html`.

También se sirve desde la API en `GET /landing` (misma carpeta).
